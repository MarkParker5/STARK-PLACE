## LLM wrapper

Write a platform-independent protocol that provides a llm via a universal interface.

Draft list of potential supported llms:
- Amazon Bedrock
- Anthropic
- GitHub
- DeepSeek
- Google AI
- LM Studio
- Mistral
- Ollama
- OpenAI
- OpenRouter
- Vercel
- Vercel AI Gateway
- xAI

Both huge modern edge-tech options and small plain on-device ones.

Ideally for local: autoload by name from the store and run inference. Alternatively, use sth else to run and host a server, than connect via localhost api.

Wrapper must implement features like formatted response, chat-like messages, and roles is these aren't supported.

Preliminary overview:

1. Top level: LLMProviderProtocol - defines a universal interface used by the app
2. Intermediate level:
LLMProvider - for modern ones
SimpleLLMProvider - for simple ones, implements advanced features via additional prompt lines and code checks (not so good as in pre-trained modern options, but still works)
3. Gateway or protocol level: exact implementation that implements http api calls / sdk calls - but has parameters for configs, like base url if same protocol used by many servers
4. Exact model level (optionall) - preset params, works from the box
