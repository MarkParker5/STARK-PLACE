# stark-place-core

The Foundation of S.T.A.R.K. Platform: parsing types and the base harness,
imported by every other `stark-place-*` module.

```bash
pip install stark-place-core --find-links https://markparker5.github.io/STARK-PLACE/find-links/
```

Provides the `stark_place.core` namespace. Depends on nothing internal.
